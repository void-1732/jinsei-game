# 人生シミュレーション — STEP 46 (v4.7.0)

GitHub Pagesでプレイできる日本語のブラウザ人生シミュレーションゲームです。生年月日は2000年内でランダムに決まります。

**ゲーム:** https://void-1732.github.io/jinsei-game/

## プレイ方法

1. プレイヤー名を入力し、人生を始めます。
2. 右側の**「次のターンへ進む」**を押すと出来事のポップアップが表示されます（開始時の最初の出来事も同様です）。
3. **3択から一つ選ぶとポップアップが閉じ、結果は右側のプレイヤー欄と人生の記録に表示**されます。もう一度開く必要はありません。
4. 希望する場合は、人生画面の**「このターンの自由行動」**で一つ行動できます。イベント選択とは別枠です。
5. 次のターンに進むと、別の出来事と新しい自由行動が発生します。

0～14歳は3か月、15歳以降は1か月ずつ時間が進みます。自由行動は**1ターンに1回**、カテゴリを移動しても上限は共有します。高能力での成長量は小さくなり、日常的な学習・技能・交流では最大95点です。

画面上部の空きスペースに9カテゴリを常時表示しています。カテゴリを押すと関連項目（学習・成績、進学・資格など）を同じページで確認できます。もう一度押すとカテゴリ内の項目タブを閉じられます。詳細な61画面の検索は右上の「全画面検索」から利用できます。

自由行動ができるカテゴリには **「● 行動可」** と表示されます。カテゴリに進むと、実行可能な行動をその場で選べます（自由行動は全カテゴリで合計1ターン1回）。人生画面にも操作可能なカテゴリへのショートカットを置いています。

保存・読み込み・新しい人生は右上の**「設定・保存」**から操作します。既存のSTEP 42・43の自動保存・手動保存も読み込めるようになっています。保存先は利用しているブラウザで、GitHubには送信されません。

## STEP 45：選択が数年後に返ってくる物語

幼少期の興味、友人や家族との関係、仕事の選択、人生後半の価値観について、**4種類の連続イベント**が追加されました。最初の決断が保存データに残り、数年後・十数年後の出来事の内容や選択肢が変わります。

- 6歳頃の興味 → 12歳・18歳・27歳頃の出来事
- 13歳頃の人間関係 → 19歳・29歳・45歳頃の出来事
- 22歳頃の仕事観 → 30歳・40歳頃の出来事
- 40歳頃の価値観 → 53歳・67歳頃の出来事

通常イベントを含め、1ターンのポップアップは従来通り**1回**です。選択後に勝手に再表示されません。人生ダッシュボードの「人生の記録」にある「過去の選択から続く物語」で、今進行している道と次の節目を確認できます。旧バージョンの保存データも引き継げます（既に過ぎた年齢の幼少期イベントは後から発生しません）。

## STEP 46：年齢や人生の状況で変わる152種類の選択イベント

**選択機能A「人生イベントを大幅追加」**を実装しました。年齢別の出来事104種類、生活状況・過去の分岐に連動する出来事24種類、思いがけない出来事24種類の計**152種類・456選択肢**を収録しています。オリジナルの文章を使用しています。

- **年齢別:** 0～2歳、3～5歳、小学生、中学生、高校生、18～24歳、25～39歳、40～64歳、65歳以降。
- **状況別:** 就職・失業・子育て・交際・体調・貯蓄・技能・STEP 45の過去の選択。条件に合わない出来事は表示されません。
- **幸運とトラブル:** 思いがけない評価、親切、忘れ物、故障、けが、天候の急変など。選択次第で体調・能力・人間関係・資金が変化します。
- **繰り返し防止:** 直近14個の通常イベントを避け、登場回数の少ない出来事を優先します（候補数が少ない年齢帯では再登場します）。
- **既存システム連動:** 進学・仕事・健康・技能・家族関係に影響を与え、STEP 45の連続イベントは引き続き優先して表示されます。
- **保存:** 追加の保存形式変更は不要。従来のSTEP 42～45データから引き継ぎます。

ターン操作は変わりません。「次のターンへ進む」→1つの出来事のポップアップ→3択→通常画面へ戻る、という流れです。自由行動はこれまでどおり任意・1ターン1回です。登場数や影響はゲーム内の架空モデルであり、現実社会の確率を再現したものではありません。
