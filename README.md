# 人生シミュレーション

**正式版 v6.0.0 — STEP 58** | 日本語のブラウザ人生シミュレーションゲーム

**[GitHub Pagesでゲームをプレイする](https://void-1732.github.io/jinsei-game/)**

2000年生まれの一人の人生を、幼少期から人生の終わりまで体験する選択型ゲームです。学習、進学、就職、家計、健康、人間関係、社会情勢、思いがけない出来事などが選択に応じて変化します。実世界の人口・制度・物価・医療・寿命を精密に再現するものではありません。

## 最初の3分で遊ぶ方法

1. ゲームを開き、名前を入力して **「新しい人生をはじめる」** を選択します。誕生日は2000年内でランダムに決まります。
2. **「次のターンへ進む」** を押すと、人生の出来事が表示されます。**3つの選択肢から1つ**選びます。
3. 選択結果は人生ダッシュボードと右側のプレイヤー欄で確認できます。**画面上部の「今月の行動」**から、7つの行動カテゴリと残り回数・候補を1画面で確認して実行できます。**18歳未満は自由行動1回、18歳以降は異なるカテゴリで最大3回**。同じカテゴリは1ターン1回です。
4. 次のターンへ進むか、**「時間をまとめて進める」** を開いて日常イベントのみ自動選択します。重要な選択には必ず停止します。
5. 進学・仕事・健康などを詳しく見る場合は画面上部の **9カテゴリ**、より詳しい項目は **「全画面検索」** を使います。

0〜14歳は1ターン3か月、15歳以降は1ターン1か月です。6歳になると「人生の夢」と「日常の時間配分」を設定できます。選択のたびに何かを必ず実行する必要はありません。

## できること

- 学校生活・成績・受験・進路・仕事・転職・給与交渉
- 家計・現金・投資・住宅・車・ローンを統合表示し、毎月の固定費と1・3・12か月先の現金残高を概算（収入・支出を固定した参考値）
- 年齢・職業・健康・現金余力・延滞状況に応じたおすすめ行動と注意点（確認するだけなら行動枠を消費しません）
- 生活費、ローン、企業や社会情勢の変化
- 体力・こころ・技能・時間配分・人間関係、18歳以降の毎月継続する健康・交流・学習習慣
- 災害・事故・病気・詐欺・幸運な出来事と事前の備え
- 20代の貯蓄・住まい・仕事・人間関係の選択が、30〜50代以降に続く長期分岐、5年後・15年後の帰結、夢・実績・エンディング
- 自動保存、手動保存、JSONファイルによるバックアップと復元

9カテゴリには関連する **61の詳細画面・項目** が含まれます。「生活・資産」→「家計・資産」の家計簿・収支で資産と将来収支の概算を一度に確認できます。重要な出来事の選択は自由行動の回数に含まず、事業の管理操作は独立した月3回枠です。個別項目の操作可否はその画面の案内に従ってください。

## 保存とプライバシー

ゲームの保存データは利用者のブラウザ内に保存され、GitHubへプレイ内容が送信される仕組みではありません。別ブラウザやサイトデータ削除への備えとして、**「設定・保存」→「保存ファイルのバックアップ・復元」** からJSONを書き出してください。JSONにはプレイヤー名や人生記録が含まれます。既存の保存形式 **schemaVersion 7** を維持しています。

## 操作と困ったとき

- PC・スマートフォンのChrome（幅1440px・390px）で自動操作検査を実施しています。その他のブラウザ・端末は検証範囲外です。
- キーボードで選択・操作できます。画面の移動履歴は **Ctrl+Alt+← / →**、画面ガイドは右上の「画面ガイド」です。
- 操作を選択しただけでは実行されません。「この行動を実行」を押して確定します。住宅・起業・家族などの専門操作は、各カテゴリの「詳しい操作を見る」から行えます。
- イベントを保留した場合は **「次のターンへ進む」** で再表示します。未選択の重要イベントは自動確定しません。
- 保存ができない場合はサイトデータの保存可否を確認し、可能ならJSONバックアップを利用してください。

## 開発・検証

静的なHTML / CSS / JavaScriptで構成され、GitHub Pagesに公開します。ローカルで検証する場合はNode.js 22以上を使います。

```sh
npm test
node scripts/qa-browser.mjs
node scripts/check-pages.mjs
node scripts/check-release.mjs
```

ブラウザ操作検査にはChromeまたはChromiumが必要です。GitHub Actionsでは自動テスト・PC/スマートフォン操作検査・公開ファイル検査に合格した場合のみGitHub Pagesへデプロイします。実行状況は **[GitHub Actions](https://github.com/void-1732/jinsei-game/actions)** から確認できます。

重大な不具合やデータ破損を防ぐことを優先し、正式版以降は原則として修正・検証・互換性維持を中心に保守します。報告窓口は **[GitHub Issues](https://github.com/void-1732/jinsei-game/issues)** です。
