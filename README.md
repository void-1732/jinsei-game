# 人生シミュレーション — 第42段階 (v4.3.0)

日本語のブラウザ人生シミュレーションゲームです。**2000年生まれのランダムな誕生日**から開始します。0～14歳は3か月ごと、15歳以降は1か月ごとに進行し、**毎ターン表示される選択ポップアップ**で行動を選びます。選択すると学力・技能・体力・精神・人間関係・所持金などに影響し、人生記録にも残ります。画面はコンパクトなプレイ画面を中心に、9カテゴリ・61画面の情報機能も維持しています。未接続機能はなお開発途中です。

**公開方法:** [GitHub Pages公開手順](GITHUB-PAGES-公開手順.md)

**ゲームの遊び方:** [日本語操作説明書](操作説明書.md)

**実装・検証:** [第41段階報告書](docs/implementation/PHASE-41-REPORT.md)

ゲーム内のセーブデータはGitHubではなく各プレイヤーのブラウザに保存されます。サイトのURLが変わると引き継げない場合があります。

**操作:** 右側の「新しい人生をはじめる」で名前を指定して開始 → ポップアップの3択から1つ選ぶ → 「次のターンへ進む」を押します。カテゴリ名はもう一度押すと閉じます。保存・読み込み・新しい人生は右上の「設定・保存」で操作してください。
