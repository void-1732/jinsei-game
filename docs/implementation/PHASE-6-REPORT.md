## 版・基準
- バージョン：0.7.0
- 基準：grand-life-simulation-phase5.zip（第5段階）
- 既存55画面ID＋学業6画面ID＝61画面。9カテゴリの構成を継続。
- 日本語を主要な表示・操作言語とする。画面IDやプログラム上の識別子は互換性のため英数字を維持。

## 今回追加した機能
1. 健康データ：身体の健康、精神の健康、体力、生活習慣（運動・休養・食生活）。
2. 月次健康処理：年齢による変化、生活習慣の自然減衰、確率による体調不良、自然回復、健康警告。
3. 健康操作：1暦月に1回の生活改善。病気がある場合の治療、診療費5,000円の現金／借入処理。
4. 社会モデル：景気・雇用・物価の架空指数、好況・通常・不況の表示、時系列ニュース。
5. 事業経営との連動：事業の売上は好況時1.05倍／不況時0.90倍。給与・税制は従来通り。
6. 選択イベント：15歳以降の4月に抽選で発生する「新年度の過ごし方」。健康・学習・関係改善の3択と結果履歴。
7. 健康・社会・人生イベント画面群、人生ダッシュボードへの実データ表示と操作を追加。
8. 乱数の月次消費を明示し、同じ初期シードと操作で同じ経過を再現可能にした。

## 制限・未実装
- 実際の日本の統計、ニュース、年表、感染症・医学的判断、保険制度等は再現していません。
- 健康数値はゲーム上の単純化モデルであり、診療費は架空の固定額です。
- 生活習慣改善は各月1回。毎月自動的に結果が反映されます。
- 事業売上のみ景気の影響を受け、給与・投資相場・生活費の景気連動は未実装です。
- 健康・人生イベントによる死亡・寿命判定、複雑な治療選択、社会の歴史年表は未実装です。
- 人生イベントは単一種類の年度選択から開始しています。選択の結果は学習・健康・家族関係の一部に反映します。
- 保存・読込、死亡、相続、長期プレイの復元は第7段階の予定です。
- 画面の「表示項目」にある未接続データと無効ボタンは将来実装用のままです。
