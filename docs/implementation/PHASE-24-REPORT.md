## 実装
1. 設備投資の参考試算 `estimateEquipmentReturns`：既存の売上補正モデルに基づき、設備ごとの参考売上寄与・月額保守費・月次参考差額・参考回収月数を計算。ゲーム状態を書き換えない純粋関数。
2. 事業画面に設備別試算の日本語表示を追加。故障中と修理中の設備は追加売上寄与0として計算。
3. 事業取引履歴に取引名の部分一致検索を追加。既存の種類別絞り込みとの併用に対応。表示だけに作用し、家計や事業資金は変更しない。
4. バージョン表示と画面下部の旧第8段階表記を第24段階へ修正。

## 注意
- 試算は設備から生まれた実際の増分利益を測ったものではない。既存の生産性売上補正を台数に按分した参考計算であり、故障損失、将来業績、返済額、税金などは反映しない。ゲームのバランス設定・既存の収支ロジックは変更していない。
- 第24段階では未接続操作の全件接続、全画面の翻訳統一、設備別の厳密な費用対効果測定までは完了していない。
