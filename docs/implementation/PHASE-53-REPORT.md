# STEP 53 — 事故・災害・詐欺・病気・幸運と人生の備え

## 追加したシステム

- `surprise53` をゲーム状態に追加。防災・防犯・応急対応の備え（0〜5）、直近発生の制限、出来事の履歴、収支を保持。
- `js/core/surpriseSystems.js` に5系統、各3択の架空イベント、備えによる被害軽減、家計台帳と健康値の連動、STEP 51の長期的な記憶への追加を実装。
- `createStoryEvent()` では既存の分岐・後日談・進路の重要イベントを優先。そのあとに予期せぬ転機を抽選し、同じ種類の連続発生を抑制。
- 選択肢を選ぶまで費用や体力の変化を確定しない。重要イベントのため、時間短縮は手動選択で停止。
- 課金は現金と負債を正確に更新。未成年の出来事は本人へ直接費用を課さず、幸運時の入金は仕事の謝礼として収入台帳に記録。
- 「自由行動」へ防災・防犯・応急対応を追加。既存の1ターン1回制限に統合し、不正・不足・上限超過では行動回数を消費しない。
- 人生ダッシュボードへ折りたたみ式の備え・発生履歴・損害軽減結果を追加。

## 保存と互換性

従来と同じ `schemaVersion: 7` とバックアップ形式で保持。既存の `surprise53` を持たないセーブは読み込み時に補完。新フィールドとSTEP 51の新しい記憶源 `surprise` を検証対象として追加。

## 検証

- 既存の回帰テストとSTEP 53新規10件の合計305件の自動テストに合格。
- Playwright + Chromiumで1440px/390pxの2画面幅を確認。セーブファイルの復元、イベントポップアップの明示的な開閉、3択後の画面復帰、自由行動による備えの変化、カテゴリの折りたたみと画面の横はみ出しを確認。
- GitHub Actionsの `npm test` とPagesデプロイを使用。社会・危機の発生確率は架空モデルであり、実世界の安全・医療情報ではない。
