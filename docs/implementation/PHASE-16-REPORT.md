# 第16段階 実装報告書

## 概要

第15段階（バージョン1.6.0）の既存構成を維持し、個人家計と個人事業の簡易会計を分離しました。61画面ID・9カテゴリを維持しています。バージョンは1.7.0です。

## 実装した内容

1. 個人の現金と事業の運転資金の分離。事業の売上・経費は事業口座のみの変動として記録し、個人の所得・税金に自動加算しない。事業口座の損益記録は取引台帳に「事業記録」として残す。
2. 創業資金30万円を個人現金から事業資金への移動として記録。個人・事業間の資金移動と、事業資金の任意引き出しを実装。純資産の計算に稼働中の事業資金・不足額を含める。
3. 廃業時に事業残金を個人現金へ返還し、事業未払金を個人負債へ移管。二重計上を回避する。
4. 勤務先の営業停止後、前職月給の半額、ただし月額10万円を上限として6か月支給するゲーム独自の簡易失業給付。自主退職は対象外。
5. 18歳以上の失業中、再就職準備を3段階まで進められ、採用選考点に1段階につき3点加算。採用後はリセット。
6. 営業停止3か月以降、任意で企業へ50万円を寄付して早期再建を支援する操作。寄付は返金されず、営業再開後は求人枠が復活する。
7. 家計・事業・求人関連画面へ新しい状態値と操作ボタンを追加。主要表示は日本語。
8. 既存の保存スキーマ7を維持し、旧セーブデータで不足する任意項目を読込時に補完。不正な数値を拒否する。

## 仕様上の制限

- 失業給付・企業再建支援・税金は現実の日本の制度を再現したものではありません。
- 事業の会計は簡易的な資金残高モデルです。売掛金、消費税、減価償却、複式簿記、厳密な所得税申告は未実装です。
- 旧データの過去の事業取引履歴は再計算しません。読込以降の取引から新会計方式を適用します。
- 事業口座には簡易的な不足額が記録され、資金不足の精密な借入契約や利息処理はありません。
- 旧版の `findJob` による就職と、新版の求人選考が共存しています。今後統合が必要です。
- 実HTTP起動・実ブラウザでの表示と保存永続性は今回の環境では未検証です。
