# 第22段階 実装・検証報告

## 基準と方針
第21段階の配布ZIP（バージョン2.2.0）を展開して更新。既存55画面ID＋学業6画面ID＝61画面、9カテゴリ、日本語表示、過去の各段階のソース・報告書を保持した。

## 実装済み
- 設備単位に状態値（0～100）、故障状態、点検回数を追加。既存保存データに項目が無い場合は正常状態として補完。
- 設備ごとの点検操作：事業資金から5,000円を支払い、状態値を25回復。点検だけで故障は直らない。
- 故障設備の修理操作：事業資金から20,000円を支払い、故障解除・状態値80へ回復。
- 月次設備状態の低下と、一定条件に達した時点での再現可能な故障判定。故障を通知・事業取引履歴へ記録。
- 故障設備1台につき事業売上15%減、最大60%減の簡易稼働率モデル。設備が存在しない事業は従来どおり。帳簿価額・償却計算とは独立。
- 事業取引履歴の絞り込み（すべて・設備・融資・事業・点検／修理）。検索操作は表示のみでゲーム状態を変更しない。
- 保存データの設備状態（状態値・故障フラグ・点検回数）に対する型・範囲検査。
