# 第5段階 実装報告書

## 目的

前段階の全61画面、9カテゴリ、既存55画面識別子を維持したまま、仕事・会社経営・家計・投資の操作と月次精算を追加する。画面内の案内は日本語を基本とする。

## 実装済み

- `js/core/economySystems.js`: 職種別の就職条件、就職・退職、3年ごとの昇給、副業、起業・廃業、生活費設定、投資購入・売却、借入返済を実装。
- `js/core/gameState.js`: ゲーム状態の `finances` とターン進行時の月次精算、行動処理を統合。UI状態とは分離。
- `js/ui/economyPanels.js`: WORK-01～WORK-05、LIFE-01～LIFE-08に実際の経済情報を表示し、一部画面に操作ボタンを追加。
- `js/ui/screenRenderer.js`: 生活画面の資産・収入サマリーを実データに接続。既存の仮置き表示項目は残し、未実装項目と区別。
- `css/phase5.css`: PC向けダークテーマの表示調整。
- 全画面のナビゲーションと既存の人物・学業機能を維持。

## ゲーム用の簡易経済ルール

- 2000年開始。18歳未満の生活費は保護者負担と仮定（プレイヤーの資産は変動しない）。18歳以降は毎月生活費を支払う。
- 初期残高は現金0円、投資0円、借入0円。初期生活費は月額85,000円。
- 職業：販売スタッフ195,000円、事務職235,000円、技術職290,000円（18歳以上）、専門職360,000円（22歳以上、大学課程修了）。いずれも額面月収。
- 勤続36か月ごとに月給15,000円昇給。副業は18歳から、月額35,000円。
- 起業は20歳以上かつ現金30万円以上。月額売上190,000円、経費120,000円。現段階では1事業のみ。
- 税金・社会保険は賃金・副業収入・事業売上の合計の10%をゲーム上の簡易負担として控除する（現実の税率・課税標準ではない）。
- 支払時の現金不足分を無利息の借入として記録する。自動返済は行わない。
- 投資評価額は月0.2%の固定増加（整数円切り捨て）。現実の市場を反映しない。
- 3か月のターンでも各月に分割して精算する。履歴は最新600明細まで保持。
- これらの値はゲームバランスの暫定値であり、所得税・社会保険・労働法・運用利回りを再現したものではない。
