## 現行の検証範囲と既知の制約

- 既存9カテゴリ・61画面の枠組み、自由行動は1ターン1回、イベントの3択、0〜14歳は3か月進行／15歳以降は1か月進行を維持。
- セーブ形式はschemaVersion 7。旧形式相当の省略フィールドは読み込み時に補完。JSONバックアップは利用者自身で保管する。
- プレイヤーの選択と数値はゲームのための架空モデル。現実の人口分布・法律・医療・経済・災害確率・寿命を再現しない。
- Chrome/Chromiumの指定された画面幅での検証であり、全端末・全OS・全ブラウザ・全補助技術の完全対応を保証するものではない。
- 各詳細画面の項目には表示中心のものもあるため、61画面すべてを独立した操作機能として説明しない。
- ページが公開されたことと、特定の利用者のブラウザの保存データを確認できたことは別。実際の利用者の個別保存状態にはアクセスしない。

## 判定と保守

公開判定はGitHub Actionsの最終コミットの実行結果に基づきます。成功時はリポジトリの正式版として維持し、以後は不具合の再現手順→テスト追加→最小修正→PC・モバイル再検証→デプロイの順で保守します。

優先順位：①保存データ・進行不能の防止、②誤操作とアクセシビリティ、③表示・バランスの不具合、④新機能の検討。新機能の追加は正式版を安定運用した後の別判断とします。
