# 第23段階 実装・検証報告

## 概要

第22段階（2.3.0）を基準に、第23段階（2.4.0）として設備保守契約、修理依頼と完了待ち、設備更新、耐久性と生産性の基本連動を追加。既存の設備を即時修理する操作は互換性のため残している。

## 実装済み

- 設備単位の保守契約を開始・終了できる。月2,000円を事業口座から支出し、入金可能な月は摩耗を軽減、故障判定頻度を低下させる。資金不足月は保守効果なし。費用は事業取引履歴に記録。
- 故障した設備の修理を依頼し、次の月次更新で修理完了。依頼時に20,000円（契約設備は10,000円）を事業口座から支払う。依頼中の二重操作を拒否。
- 指定設備の売却と新品購入を同一操作で精算する設備買い替え。旧設備の帳簿価額と経年補正に基づく売却額、新設備の購入額の差額を事業資金へ反映。新設備の台帳を採番し直す。
- 設備種別ごとの劣化倍率（標準1、事務機器1.2、製造機械0.8、車両1.4、店舗設備0.9）。月次摩耗は整数化し、最低1点。
- 稼働設備の状態に応じた簡易生産性補正（売上に最大12%の増加）。故障台数に応じた既存の売上減少は維持。
- 事業画面に保守契約、修理依頼、買い替え、直近生産性と稼働台数を表示。操作は日本語。
- 旧保存データで不足する保守・修理項目を読込時に補完。不正値は保存データの検証時に拒否。

## 互換性・留意点

- 従来の即時修理操作を保持。新しい修理依頼は追加方式であり置き換えではない。
- 設備の帳簿価額と減価償却、融資返済、個人・事業口座の分離は既存方式を維持。
- 生産性と故障・耐久性はゲーム独自の簡易モデル。経営・工学上の現実的な予測ではない。
- 修理依頼は経過月数1の簡易モデル。修理業者・部品在庫・複数月工事・設備停止損失の詳細は未実装。
- 従業員・顧客ごとの生産性、保守費用の未払処理、全61画面の機能完全接続は未完成。
