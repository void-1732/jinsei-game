# 第15段階 実装・検証報告

## 実装範囲

- 第14段階の構造・既存61画面ID・9カテゴリを維持し、日本語で操作可能な企業・事業画面を拡張。
- 勤務先企業が営業停止したとき、当月末に雇用を終了。翌月以降の給与を停止し、失業の履歴・通知・回数を記録。別企業への採用選考から再就職可能。
- 営業停止企業は求人枠を0に固定し、12か月経過すると外部資金注入による簡易再建を行う。業績・採用枠・従業員数を初期再建値に変更。再建まで収支は発生しない。
- 自分の事業に運転資金・資金不足額・連続赤字月数・営業状態・月次資金繰り履歴を追加。資金不足を伴う赤字3か月で休業、10万円以上の運転資金があれば再開できる。
- 事業への追加資金投入は個人の現金から控除し、事業側管理指標に振替（支出集計には二重計上しない）。
- 既存セーブデータには不足する新フィールドを読み込み時に補完。新フィールドは数値範囲と履歴構造を検証。

## 財務モデルの留意点

事業の「運転資金残高」は第15段階で追加した簡易的な経営管理指標で、既存の個人家計会計と二重計上しないため、厳格な複式簿記ではありません。「累積資金不足」も参考値で、個人の借入残高とは別に表示します。第15段階の企業再建は架空のゲーム規則で、実際の企業再生・雇用・税法制度の再現ではありません。
