# 第18段階 実装報告書

## 基準と互換性
第17段階（1.8.0）のZIPを基準とし、第18段階（1.9.0）を実装しました。既存55画面と学業6画面、計61画面ID／9カテゴリは変更していません。日本語表示を維持しています。ゲーム状態と画面状態の分離を継続しています。

## 実装済み
1. **事業融資の簡易審査**：既存融資の1回50万円・総額200万円の制限に加え、事業の運転資金・月商と未払金に応じた借入上限を適用。審査回数を記録。架空のゲーム用審査モデルです。
2. **元本の月次返済計画**：月0～50万円を設定。設定した場合のみ月次返済、事業資金不足の月は返済可能額まで。完済時は自動停止。既存の手動返済も保持。
3. **設備の減価償却**：毎月帳簿価額の1%（最小1円）を非現金費用として減額し、累計減価償却額と事業台帳に記録。既存の設備売却・廃業前整理に反映。
4. **事業未払金精算**：事業口座から未払金の一部または全部を支払い。個人家計からは自動支出しない。
5. **月次推移**：事業は直近12か月の利益を棒グラフ表示、家計は台帳の月次収入・支出合計から直近12か月の純収支を表示。日本語ラベルと各月の金額ツールチップ付き。
6. **旧保存データ補完**：第17段階までのデータにない任意項目をゼロで補完。新項目の負値などを保存データ検証時に拒否。
7. **内部の旧就職操作**：既存テスト・互換性保護のため残置。求人画面では企業別採用選考を利用。
