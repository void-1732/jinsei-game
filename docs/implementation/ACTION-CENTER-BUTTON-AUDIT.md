# 操作ボタン監査・共通自由行動センター

## 問題
- 以前の画面一括判定では、詳細画面の属するカテゴリを消費すると、操作ではない選択・ナビゲーションボタンまで無効になる可能性があった。
- 自由行動がホーム・カテゴリごとの概要・詳細画面に重複配置され、行動候補と残り枠を一か所で比較できなかった。
- ゲーム本体にあるアクション名とUIの接続を全体的に検証するテストが不足していた。

## 解決
1. すべての画面のヘッダーに「今月の行動」ボタンを設置。操作を開閉できるモーダルに7カテゴリ・残り枠・実行済みの状況・今できる候補をまとめる。
2. ボタンを一度押すと候補が選択され、画面下部の「この行動を実行」で初めて確定。失敗した場合は理由を表示し、成功した場合は残り枠を即時更新する。
3. 各カテゴリには「このカテゴリの詳しい操作を見る」を置き、住宅の任意ローン返済・事業設備管理など詳細な操作は従来画面で継続できる。
4. ホームとトピック概要の重複した自由行動ピッカーを、共通センターを開く小さな入口へ置き換える。
5. 詳細画面の全ボタンを一括無効化する処理を撤去。管理・選択・ナビゲーションは維持し、最終的な実行可否・回数・カテゴリをゲームストアが判定する。
6. ゲームストアの全操作名・UIボタンに使われるアクション名をテストで照合。未登録ボタンを新たに追加した場合はテストが失敗する。

## 維持する仕様
- 18歳未満：各ターン1回。18歳以上：異なるカテゴリで最大3回、同一カテゴリは1回のみ。
- 重要イベントを未選択の間は自由行動不可。事業設備・融資など管理操作は独立した3回枠。
- 失敗した操作は残数を消費しない。
- 9つのナビゲーションカテゴリ、61画面ID、保存schemaVersion 7、旧セーブ・継続習慣・既存のローン/事業/家族の状態を維持。

## 検証・公開条件
- `npm test`、公開対象検査、正式版回帰テスト、1440px PC・390px スマートフォンの実ブラウザ操作をすべて成功させる。
- PC・スマートフォンで共通センターを開閉し、実際の成人3カテゴリの行動を連続実行することを検証。
- 全検証に成功しない場合、`main`への統合・GitHub Pages公開を行わない。
