# 第11段階 実装・検証報告

## 基準と仕様
- 基準ファイル：第10段階 ZIP（v1.1.0）。第11段階：v1.2.0。
- 既存の61画面IDと9カテゴリは変更なし。PC専用の暗色表示・日本語の主要操作を継承。
- ゲーム状態と画面状態は引き続き分離。第10段階以前の保存データをロードした際に追加項目を補完。

## 今回実装した項目
1. 勤務先があるプレイヤーの業務成果、上司からの信頼、同僚との関係（0～100点）。
2. 仕事への集中・同僚の支援・上司面談の操作。各ターンの職場行動は最大2回。翌ターンに回数を初期化。
3. 勤続3か月以降の人事評価、直近24件の履歴、昇進に必要な最低限の業務成果・信頼の条件。
4. 従業員個別データ（技能・意欲・月額人件費）、採用・研修・退職・働きやすさ改善。
5. 従業員技能と意欲をゲーム内事業売上に反映。実際の人件費を経費に使用。
6. 事業の従業員・平均技能・平均意欲に関する月次記録（直近36か月）。
7. 既存の仕事・経営関連画面に実操作を追加。画面内の主要な操作表示は日本語。
8. 新規データの保存形式検証、旧バージョンの保存データの読み込み時の初期値補完。

## 制限・未実装
- 上司・同僚は現時点では個人プロフィールを持たない集計値。実在企業情報の再現や職場内の個別人間関係は未対応。
- 経営の業績記録は簡略版であり、法人会計・資金調達・従業員個別の勤務契約・実際の税制は未実装。
- 人事評価は現在はプレイヤー操作で記録する方式。詳細な毎期自動査定は未対応。
- 旧セーブのスキーマ番号は互換性維持のため「7」を継続。
