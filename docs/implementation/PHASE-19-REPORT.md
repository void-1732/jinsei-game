# 第19段階 実装報告書

## 基準
第18段階（1.9.0）を基準として第19段階（2.0.0）を実装。既存55画面＋学業6画面の合計61画面ID、9カテゴリと日本語操作表示を維持しました。

## 実装済み
- **融資期限**：新規借入から36か月後を初期期限とし、追加借入時は既存期限と比較して延長。旧データでは期限未設定の融資を従来仕様で扱います。
- **延滞・信用評価**：期限以降に元本残高がある月は延滞を加算し、信用点数を減算。延滞中は新規融資を停止。元本完済で延滞を解消します。
- **返済条件変更**：延滞融資を12か月延長できる操作を追加。信用点数を減算します。
- **設備個別台帳**：設備購入ごとに識別番号・取得価額・現在価額・残耐用月数を登録。100か月の簡易償却を行い、旧設備残高しかないデータは旧来の月1%償却を維持します。設備一括売却時には台帳をクリアします。
- **画面**：融資の信用評価、期限、延滞月数、個別設備の残価、延滞融資の条件変更ボタンを仕事・事業画面へ追加。
- **データ保護**：新項目の型・範囲・個別設備合計値を保存時に検査。旧データには安全な初期値を補完します。
