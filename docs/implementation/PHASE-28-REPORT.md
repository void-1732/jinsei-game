# 第28段階 実装報告 — 住宅資産・住宅ローン・地域経済・簡易年金

## 実装
- 既存61画面・9カテゴリ、旧保存形式（形式番号7）を維持。
- 持ち家の現金購入に加え、頭金20%、返済期間360か月、ゲーム内月利0.3%の住宅ローン購入を追加。
- 元本残高と利息を月次精算し、繰上返済、売却時の残債精算、残債超過時の売却拒否を追加。現金不足は既存家計の個人借入に記録。
- 持ち家参考評価額－住宅ローン残高を純資産と死亡時の簡易相続評価に反映。住宅の評価は固定参考価格であり市況連動ではない。
- 10地域の生活費係数（90～100%）を基本生活費の差額として月次精算。東京は従来どおり。地域就業係数は採用評価に小幅な補正。実在の物価・賃金統計ではない。
- 18歳から加入月数を計上し、120か月以上で65歳から月額6万円の架空の簡易老齢年金を支給。日本の実制度とは異なる。
- 住居画面にローン残高・月額返済・繰上返済、家計画面に年金履歴、地域画面に係数を表示。
- 旧セーブデータにない項目は読込時に初期化し、異常な数値を検出。

## 制約・未実装
- 住宅価格の変動、借換審査、個別融資契約、現実の社会保険・医療保険、地域限定求人、年金加入期間による細かな給付額、公的年金の実制度は未対応。
- 住宅ローンは支払不足時に個人借入へ振り替わり、延滞債権管理は行わない。
- 実ブラウザの永続保存と利用者PCでの動作は別途確認が必要。
