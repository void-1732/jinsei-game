# 第29段階 実装報告

バージョン 3.0.0。第28段階の配布ZIPを基準に既存コード・61画面ID・9カテゴリを維持して更新。

## 今回の追加
- 住宅ローン残高と固定月額に基づく、最長12か月の元本・利息・支払額・予定残高表示。
- 月次返済時の実際の現金充当額、資金不足額、延滞月数、返済履歴（最大60か月）。不足額は既存の個人負債にも記録され、延滞累計は情報表示専用。二重の債務計上はしない。
- 持ち家の地域別・月次価格変動（架空係数）、住宅経過月数、50,000円の修繕と30,000円の評価改善。住宅評価額とローン残高の逆転を有効状態として扱い、売却は従来の残債精算制限を維持。
- 年金加入記録の月次加算と、65歳以降の簡易給付。加入120～240か月は従来の月額60,000円を維持し、240か月超では加入期間に応じて月額上限24,000円を加算。
- 診療時のゲーム独自の簡易公的医療保障。標準診療費5,000円に対し本人負担3,500円、差額1,500円を保障による軽減実績に記録。
- 住居・家計・保障画面への表示と、修繕操作の接続。既存セーブの欠損項目は読込時に補完。

## 留意点と未実装
- すべて架空のゲーム用モデル。実際の日本の社会保障・住宅ローン契約・税制・不動産価格を再現しない。
- ローン元本は従来の返済計算どおり減少し、支払不足分は個人負債で処理。延滞額は追加の借入元本ではなく履歴指標。
- 公的医療保障は治療行動に限定した簡易負担軽減。診療科別計算や自己負担上限、年金納付額の会計処理は未実装。
- 地域別の求人職種・企業所在地・給与相場を厳密に再現する機能は未実装。
- 実HTTP経由のブラウザ起動、実ブラウザ再起動後の保存保持、全61画面の人手操作確認は今回未実施。
