# 第14段階 実装・検証報告

## 目的・基準
- 第13段階（v1.4.0）のZIPを基準に、既存のゲームファイル、61画面ID、9カテゴリ構成と日本語表示を維持。
- 第14段階（v1.5.0）では架空の企業6社の財務・求人の連動を拡張。

## 実装済み
- 企業ごとにゲーム内円で売上、経費、月次利益、資金残高、経営危機継続月数、営業状態を管理。
- 企業の業績、在籍人数、景気に基づいて月次収支を計算。月次財務履歴は直近24か月分を保存。
- 資金不足と赤字が3か月連続すると「経営危機」、6か月で「営業停止」。経営危機・営業停止中は新規募集枠を0にする。
- 各企業の財務・求人情報を仕事画面で表示。営業停止企業への応募は不可。
- 第13段階以前のセーブデータは財務情報を補完する。新形式の財務項目に不正値がある場合は読込拒否。
- 日本語表示を継続。

## 検証済み
- Node.js 自動テスト68件成功（従来63件＋新規5件）。
- 企業ごとの独立性、月次損益の一致、資金不足・営業停止、募集停止、決定性、旧セーブの補完、不正な財務値の拒否、年月進行を確認。
- 61画面ID・9カテゴリの登録を確認。JavaScriptの構文検査・ZIP整合性検査を実施。

## 重要な制約
- 企業財務は完全に架空の単純モデル。現実の決算、金融・税制、破産手続きは再現していない。
- 営業停止は新規応募の拒否・求人停止・財務更新停止を指し、**在職プレイヤーの自動解雇、既存雇用契約の清算、企業再建・法的倒産は未実装**。
- 所有する個人事業の経営や給与、税金の詳細財務三表は未実装。ゲーム全体は試作版。
- 実HTTP経由のブラウザ起動、実ブラウザでの全61画面描画、長期保存の再起動テストは今回未実施。

第15段階では営業停止に伴う雇用・給与処理の整合性、企業再建、個人事業の資金繰り、経営バランス、画面操作のブラウザ統合検証を優先。
