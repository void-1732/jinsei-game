# 第31段階 実装・検証報告

## 基準ファイルと互換性
第30段階 v3.1.0 のZIPを展開して修正。バージョン3.2.0。既存55画面IDと学業6画面、合計61画面・9カテゴリは変更していない。元コード・従来の報告書を収録。ゲーム状態と画面状態は分離したまま。

## 実装済み
1. 住宅ローンの借入審査。信用55点未満を拒否し、個人負債、月次返済負担（給与がある場合は収入の45%以内）、無収入の場合の6か月分返済余力を確認。現金一括購入には新審査を適用しない。審査に落ちても住居・資金残高は変更しない。
2. 年金の月次納付区分（通常納付・免除・未納）を家計画面から切り替えられる。通常納付は既存の月4,000円を精算し加入実績を満額計上。免除は保険料0円・受給算定上は半月分の評価、未納は保険料0円・加入実績に不算入。現実の日本制度とは異なるゲーム独自の簡易モデル。
3. 未納記録から最大12か月を現金で追納する操作。追納は1か月4,000円を支払い、未納月数を減らし、満額加入実績を加算。払い過ぎ・資金不足・不正な月数を拒否。年金受給見込みには加入実績を参照する。
4. 診療費5,000円・簡易公的負担1,500円・本人負担3,500円・任意保障の別途給付見込みを保険画面へ明記。既存の給付処理は変更しない。
5. 住宅ローン信用と年金状況の画面表示、固定費への通常納付年金保険料表示を追加。日本語表記を維持。
6. 旧セーブの新規キーを補完。新規の納付区分・未納年月等を検証し不正な値を拒否する。

## 未実装・注意点
- 融資はゲーム用の簡易審査。厳密な返済負担率・延滞元本・担保評価、保証会社や金利変動、金融機関ごとの審査は未実装。
- 既存の住宅ローン支払不足は予定元本を減らし未納分を個人負債に加える旧会計方式を継続。実務上の延滞元本と一致しない。
- 年金の納付区分はプレイヤーが手動変更する方式。自動所得審査、免除申請、追納可能期限や追納加算額は未実装。
- 任意保険の給付は従来どおり病気に対して一度の定額支給。医療費上限・免責・実費補償の精算は未実装。
- HTTPサーバーでの起動、実ブラウザ61画面の描画、ブラウザ終了・再起動後のセーブ保持は今回は未検証。
