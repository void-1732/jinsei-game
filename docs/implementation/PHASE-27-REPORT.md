# 第27段階 実装報告

## 概要
第26段階を基準に、居住地域・住居種別・引越し・住居費・任意保障を実装。既存55画面と学業6画面、9カテゴリは維持。新しい画面IDは追加しない。

## 実装済み
- 日本国内の10地域：北海道・札幌、宮城・仙台、新潟・新潟、埼玉・さいたま、東京・東京23区、愛知・名古屋、大阪・大阪、香川・高松、福岡・福岡、鹿児島・鹿児島。
- 実家／賃貸／持ち家。賃貸初期費用は月額家賃2か月分。持ち家の簡易購入額は地域基準家賃×180、諸費用は購入額の3%。旧持ち家売却は帳簿額の90%。
- 18歳未満は保護者負担。成人後の基本生活費85,000円（変更可能）とは別に住居費・保険料を月次精算。足りない費用は既存の個人負債として扱う。
- 任意保険：未加入／基本保障（月3,000円・体調不良時15,000円）／充実保障（月7,000円・体調不良時40,000円）。同一の継続疾病では1回のみ給付を請求可能。
- LIFE-02（住居）、LIFE-03（家計）、LIFE-07（保険）、SOCIETY-06（地域）に、実データ投影と日本語の操作を追加。
- 現行のゲーム状態とUI状態の分離を維持。住居・保険情報は既存のfinancesに格納し、旧形式の保存データには安全な初期値を補完する。
- 保存データの型・範囲・履歴長検証を追加。新規操作は既存の履歴・自動保存へ連動。

## 検証済み
- npm test：137件すべて成功（既存131件を表示仕様に合わせて更新、新規6件）。
- 61画面の登録と画面項目の投影・互換性は自動テストにて検証。
- JavaScriptの構文検査、ZIPの整合性検査。
- 18歳未満の操作拒否、引越し費用・家賃の分離、持ち家売却、保険料・給付・二重請求防止、旧形式のセーブデータ読込、決定性。

## 未検証・未実装
- 実HTTP経由のブラウザ起動、Chromiumでの全画面操作、ブラウザ再起動時の永続保存は、アクセス遮断により未検証。
- 日本の現実の家賃・価格・健康保険・年金制度との整合性は対象外。金額はすべて架空のゲーム用設定。
- 住宅ローン、不動産評価変動、同居家族と生活費の分担、転勤、地域別求人、公的医療保険・年金、保険請求の詳細審査は未実装。
- 持ち家資産を人生終了時の相続・純資産評価に統合する処理は未実装。
- すべての画面に残る予定操作や未接続項目は継続課題。

## 起動方法
ZIP内の `start-windows.bat` などを使用し、PCのローカルHTTPサーバーから起動してください。ブラウザ設定によって保存領域が消去される場合があります。
