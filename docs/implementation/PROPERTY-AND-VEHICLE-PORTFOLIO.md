# 複数車両・不動産登記・任意ローン返済

## 所有と登記
- 車は最大5台。個別の評価額・経過月数・維持費・売却。
- 不動産は現在の自宅を含め最大5件。旧方式の自宅はそのまま残り、別荘・賃貸運用物件を追加所有できる。
- 不動産ごとにゲーム内登記番号、所有者、登録年月、購入地域、用途、取得価格、現在評価額、ローン残高・毎月返済額・延滞利息を記録。
- 登記は法的な登記・本人確認・不動産契約とは無関係なゲーム内台帳。

## ローン
- 自宅住宅ローン：任意の月額返済額と任意の繰上返済額を円単位で設定する。旧方式の返済会計と既存の残高は継続。
- 追加物件：個別ローン（頭金20%、ゲーム内の月利0.3%、上限36? * 10=360か月相当）。月額任意設定、繰上返済、未払利息清算。
- 個人借入は従来の入力可能な返済額を継続。事業融資は既存の契約別・全体の返済設定を継続。
- 追加物件の月次返済は、利息と元本を分けて精算。元本が不足しても借入債務を消さない。売却時は残債と未払利息を差し引く。

## 家計・資産
- 追加物件の賃料収入・維持費・修繕引当・ローンを各月に反映し、不動産評価額を小幅に推移させる。
- 車両維持費と減価を保有台数ごとに反映する。
- 純資産・相続には追加車両と追加物件を各1回だけ計上する。

## セーブ互換
- 保存形式v7は変更しない。既存の単一住宅 `finances.living`、車両 `finances.vehicle` を維持。
- 新規任意項目 `finances.vehicles`、`nextVehicleId`、`living.properties`、`nextPropertyId`、`primaryRegistration` を検査。
- 旧データは補完し、既存の車と家を消去しない。

## UI方針
- 既存の「住まい・車」だけで管理。画面数を増やさず、複数所有・物件登記・返済入力をカード・ボタン・開閉領域にまとめる。
- 長い候補一覧は折り返す。金額のみ数字入力とし、物件・用途・支払い方法はボタン選択。
