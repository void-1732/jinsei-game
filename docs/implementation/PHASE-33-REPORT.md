# 第33段階 実装・検証報告

## 対象
第32段階（v3.3.0）を基準とし、61画面・9カテゴリと既存のセーブ形式を維持したまま、住宅ローン・年金・任意保険の会計照合を追加。表示は日本語を原則とする。

## 実装した内容
- 読み取り専用の `auditLivingAccounts` 関数を追加。住宅ローン元本と未払利息、延滞残高、年金未納記録、追納月数、医療保障累計を参照できる。
- 実額返済方式で、未払利息が延滞残高を超える場合、元本完済後に未払利息が残る場合を照合結果として報告。
- 住居画面に「会計整合性」の表示、家計画面に「追納可能な未納記録」の件数を追加。
- 住居の買い替え・売却時、実額方式で発生した未払利息を売却時の返済必要額に含める。買い替え完了後は旧ローンの未払利息を消去する。
- 給付見込みが0円の場合、任意保障の請求を拒否する。
- 初期ローンの従来方式を維持し、実額方式への切替はプレイヤーの明示操作による（既存テストと保存データとの互換性を維持）。

## 検証
- `npm test`：175件中175件成功（既存169件＋新規6件）
- 全 JavaScript ファイルの `node --check`：成功
- 61画面IDについて、既存登録ファイルを変更していない。
- ZIPアーカイブの内容検査：実施

## 制限・未完成
- 会計照合は異常を表示する機能であり、自動修復ではない。
- 旧住宅ローンの従来方式は維持されており、その計算上の負債処理を完全に統一していない。
- 住宅ローンの利息・年金・医療制度はゲーム独自の簡易モデルで、実際の日本の制度を再現するものではない。
- 実HTTPサーバー経由のブラウザ起動、全61画面の実ブラウザ操作、実ブラウザでの永続保存は今回未検証。
