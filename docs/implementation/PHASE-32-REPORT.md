# 第32段階 実装・検証報告

## 概要
第31段階 v3.2.0 を基準に v3.3.0 を作成。既存の55画面IDと学業6画面の計61画面、9カテゴリ、保存データの基本構造を維持。新規表示・操作は日本語。

## 実装
1. **住宅ローンの実額返済方式**：従来方式から明示操作で切替可能。未払元本を架空返済せず、実際の現金支払額に応じて残高を減少。未払利息を別管理。延滞解消時は未払利息、元本の順に充当し、実額方式では個人負債へ同額を二重計上しない。旧保存・旧ローンは「従来方式」を保持。過去の延滞がある間は切替を拒否。
2. **年金の所得審査付き免除申請**：給与・有効な副業収入の合計が月12万円以下の場合に申請可能。免除モードを設定。従来の手動区分変更も互換性のため継続。
3. **年金の年度別記録**：毎月の納付区分と追納実績を記録し、年度別に納付・免除・未納・追納の件数を表示。旧セーブ以前の年度別内訳は復元できないため捏造しない。
4. **任意保険の給付上限方式**：従来の定額方式を維持しつつ「自己負担上限」を選択可能。請求時は標準診療費から簡易公的保障を除いた本人負担額と契約給付額の小さい金額を支払う。
5. 各機能を住宅・家計・保険画面に追加。保存データ検証に新規項目の異常値検査を追加。

## 検証
- 既存162件と新規7件、計169件の Node.js 自動テストを実行。
- JavaScript構文、61画面ID登録、ZIP CRCの整合性を確認。
- 実HTTPサーバー起動、実ブラウザでの全画面表示、実ブラウザ再起動後の永続保存は未検証。

## 現時点の制約
- 実額方式は既存住宅ローンの明示切替制。すべてのローンを自動変換するものではない。
- 延滞元本と未払利息は簡易モデル。遅延損害金、督促・差押え等は未実装。
- 免除申請はゲーム内月額所得基準のみ。扶養・世帯所得・現実の制度は未対応。
- 保険請求の実費上限は現時点で一回の簡易診療費が基準。高度な診療別の費用精算は未実装。
