# 進学・資格・就職の連動（レビュー用）

## ゲーム内の進学先と修業年限
- 難関大学・総合大学・地域大学・国公立大学・私立大学：4年制
- 短期大学・専門学校：2年制
- 基本月額学費：難関大学48,000円、総合・地域大学36,000円、国公立28,000円、私立52,000円、短期大学24,000円、専門学校30,000円。ゲーム内の架空金額であり、現実の統計ではない。
- 従来の「大学」内部ステージ名は全校で維持し、画面では学校名・課程・修業年限を表示。

## 選択と将来のつながり
- 入学後、「進学・資格・履歴」の「進学・受験」画面で5分野（総合教養、情報・IT、経営・会計、福祉・医療補助、デザイン・企画）をボタンから選択。
- 専攻選択は既存の1ターン1行動の制限内。変更は保存され、卒業時に架空の修了認定が付与される。
- 専攻と認定が関係する求人の評価を最大13点加算し、採用後は月給を最大13,000円上乗せ。既存の面接・学力・技能・企業採用条件も継続。
- 専門職の求人条件は「4年制大学修了」。短期大学・専門学校の修了では応募できない。旧セーブの大学修了判定はそのまま有効。

## セーブ互換
- スキーマv7を維持し、教育データの`program`、`major`、`credentialIds`、`qualifications`を任意項目として検証。
- 旧セーブに`program`がなければ従来の4年制進行を維持し、予期しない早期卒業を防止。
- 18歳以降の既存の職歴・保険・投資・住宅・家族等は変更しない。

`npm test`、公開対象検査、正式版検査、1440pxと390pxのブラウザ確認がすべて成功した場合のみ本番へ統合する。
