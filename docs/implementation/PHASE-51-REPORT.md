## ゲームロジック

1. 6〜85歳の重要な選択を、学び・仕事・人間関係・家計・健康の5分野に分類して記録。同じ分野での記憶登録は8歳差以上に限定。
2. 記憶した選択は原則5年後と15年後に専用イベントとして再登場し、当時の選択内容を示す。年齢が重なった場合は既存の長期分岐を優先する。
3. 「継続」「周囲と協力」「方向転換」の3選択を実装。結果は能力や関係性へ反映し、影響力を保存する。
4. 過去の学び・仕事の蓄積は就職の採用点へ最大+6点補正。健康面での継続は病気発症確率を最大35%低減。家計を見直す選択で支出を月1000円減額（最低支出額の制約あり）。仕事の継続は条件を満たした場合に少額の昇給。
5. 重要な後日談は時間短縮中に自動確定しない。選択待ちの時は次のターンへ進めない。
6. 人生の記録に将来の再会予定を折りたたみで表示。実績・エンディングの節目には重要な後日談の選択も反映。

## 制限と今後の改善余地

- 本システムは架空のゲームバランスであり実社会の制度や人生を定量化するものではない。
- 過去の選択の強い影響は現在は代表的な5分野と定期的な後日談に限定し、人物固有の関係史や複雑な進路分岐は今後の拡張対象とする。
- これらのテストはすべての可能な人生状態の完全検証を意味しない。
