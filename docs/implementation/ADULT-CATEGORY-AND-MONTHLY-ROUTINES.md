# 18歳以降のカテゴリ別自由行動と毎月の継続習慣

## ルール
- 0～17歳：自由行動1ターン1回。従来の仕組みを維持。
- 18歳以上：自由行動1ターン最大3回。ただし異なるカテゴリで実行。同じカテゴリは月1回。
- 「人生」「生活・資産」「人物・家族」「学業」「仕事・経営」「健康」「社会」を分類軸とする。画面数やカテゴリ数は増やさない。
- 重要イベント・人生の選択は自由行動枠を消費しない。未選択の重要イベントがある間は自由行動を開始できない。
- 起業の設備・融資などの事業管理は従来の独立3回枠を維持する。事業の設立・廃業と個人キャリアの重要選択は通常カテゴリ枠。
- 無効な選択・資金不足・条件未達の操作は自由行動の回数を消費しない。
- サーバー側のゲームストアでカテゴリと回数を判定し、ボタンの非活性化だけには依存しない。

## 自由行動の追加
- 健康：フィットネス講座、メンタルケア講座、健康診断
- 人物・家族：家族と外食、友人と外出
- 学業：オンライン講座、読書・教養講座
- 仕事・経営：キャリア交流会
- 社会：地域のボランティア
- 既存の「学習」「仕事探し」「投資」「住宅」「友人・家族」「治療」「習慣」は引き続き利用可能。
- 実行すると現金支出、体力・精神・技能・関係値が小幅に変動。行動費用と結果を家計・履歴に記録。

## 毎月継続するプラン
- 「健康」：ウォーキング、ジム、心のケア／瞑想
- 「人物・家族」：家族への連絡、友人との月1回の交流、家族の食事
- 「学業」：読書、オンライン講座、英語
- 各分類1プランを保持し、次月以降に支払可能な月だけ費用と効果を反映。停止プランあり。
- 資金不足時は引落しせず今月の効果も保留。勝手に借金を発生させない。
- 月次精算は重複実行防止。長期プレイ・まとめて進める機能でも月ごとに計上。
- 継続プランの変更は当該カテゴリ自由行動を1回使用する。
- 既存のSTEP 54「日常の時間配分」は独立して継続。二重の無料給与や大量の能力上昇は付与しない。

## UIとセーブ
- 既存カテゴリ内の自由行動は選択ボタン＋確定ボタン。ホーム画面ではまとめて開く。
- 上部のカテゴリに「行動可／済」を個別に表示。残り回数は常時表示。
- `turnActions.categories` はカテゴリー別使用記録。既存v7の`used`と`lastAction`は維持。
- `monthlyRoutines` は追加任意フィールド。古い保存データは停止プランで補完。
- 旧データに分類記録が無いときは「以前の行動」として消費済み回数を引き継ぐ。

## 検証
`npm test`、長期プレイ・保存互換、PC/スマートフォンのブラウザ検証、GitHub Pagesの公開検査をすべて通過した場合に限りmainへ統合する。
