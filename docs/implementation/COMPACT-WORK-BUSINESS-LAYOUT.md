# 副業・起業・経営のコンパクト化（画面ID・保存データは変更なし）

## 課題
- 副業画面に六つの求人カードが縦に並び、給与・勤務時間・選択ボタンが繰り返される。
- 起業後は、毎月の売上・運転資金・設備情報などの要約が複数個所に重複し、貸付契約・返済予定・従業員・取引履歴の全表示で非常に長いページになっていた。
- 必要な操作まで何度もスクロールする状態だった。

## 新しい画面
- **WORK-03 アルバイト・副業**：現在の副業・勤務時間・月収の3つを要約し、6業種は小さな選択ボタンに集約。選択中の時給・時間・月収見込を同じ場所に表示し、「開始・切替」「停止」の2操作にまとめた。
- **WORK-04 起業・経営**：営業状態と管理操作残数を一行で表示。売上・経費・利益・運転資金・融資・設備/社員の6指標だけを最初に表示。
- 下部は「経営・方針」「設備」「融資・資金」「従業員」「履歴・指標」の5タブに統合し、**表示する管理タブは同時に一つだけ**とする。契約別返済額・取引明細・履歴は各タブの折りたたみを開いて確認する。
- PCでは指標を3列・操作を横並び、スマートフォンでは2列・必要に応じて縦積み。選択ボタンは44px程度の高さとキーボード操作を確保する。
- 画面上部の別のキャリア予測は、WORK-03/04では初期状態で折りたたむ。

## 維持する機能
- 本業と副業、起業・廃業、経営方針、融資借入・返済・月額設定・契約別設定・延滞条件変更、運転資金の移動、設備の購入・点検・保守・修理・売却・入替、人事・研修・職場改善・取引明細。
- 18歳以上のカテゴリ別3回の自由行動。融資・設備等の管理は独立した3回枠。実際の可否は既存のゲーム本体が検証する。
- ゲームの保存形式v7、従来の画面ID（WORK-03、WORK-04）、経済計算、履歴と長期プレイ。保存データの変更やゲームルールの変更はしない。

## 品質ゲート
- 全自動テスト、旧セーブのロード、1440px/390pxのブラウザ操作確認、公開ファイル検査をすべて成功した場合にのみ本番へ統合・公開する。
