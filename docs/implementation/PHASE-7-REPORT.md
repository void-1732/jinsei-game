# 第7段階 実装・検証報告書

## 基準と保護
- 基準ファイル：`grand-life-simulation-phase6.zip`（第6段階）
- バージョン：0.8.0
- 既存55画面IDと学業6画面IDの合計61画面、9カテゴリは変更していません。
- ゲーム状態と画面状態を分離し、既存の職業・健康・学業等の処理を引き継いでいます。
- 画面の主要な説明・操作・通知は日本語です。内部のIDや互換性維持に必要なファイル名は英語のままです。

## 今回実装
1. 自動保存：ゲームの開始、時間進行、アクション、イベント確認ごとにブラウザのローカル保存領域へ記録。次回起動時に読み込みます。
2. 手動保存：3枠を提供。自動保存・人生記録を含め合計5枠を選択可能。
3. 保存データの検査：仕様番号、必須項目、検査用ハッシュ、JSON解析の検証。現行データを上書きする際には直前の正常データを予備として保存。破損時は予備を読み込みます。
4. 保存・読込・人生の再挑戦ボタン。人生を初期化して再度プレイできます。人生記録枠は再挑戦によって削除されません。
5. 40歳以降、健康と年齢に応じた確率による死亡判定。110歳では必ず死亡。死亡後の時間進行およびゲームアクションは停止。
6. 死亡時に、ゲーム独自の簡易人生評価と正味資産・仮の相続税・家族への分配額を計算。死亡後に「人生記録」枠へ記録。
7. 「履歴」画面に最近のイベント履歴70件と死亡後の評価・相続結果を表示。
8. 保存と再開でも、乱数の状態・ターン数・イベント履歴・健康・学業・家計を復元。

## 制限・未実装
- 保存はブラウザのローカル領域のみ。端末間同期、クラウド保存、ZIPへのセーブデータ埋め込みはありません。ブラウザの閲覧データ削除で消失する場合があります。
- 現状は単一の生涯を再開始する方式。家系の別人物への操作移行、複数世代の本格的な継承プレイは未実装です。
- 世代保存は人生記録枠に死亡状態を残す簡易実装です。人生記録は最後に終了した人生で上書きされます。
- 死亡・相続は簡易モデルで、実際の死亡統計・日本の相続税・法律・遺言・扶養や家族の死の追跡を再現しません。
- 死亡判定は40歳以降ターン単位で実行されるので、実際の死亡率や個別医療リスクと同一ではありません。
- 過去のイベントは最大1200件、履歴画面の表示は最近の70件です。
- 保存データの構造や合計整合性のすべてを検証しているわけではなく、チェックサムは悪意ある改ざんへの暗号学的保護ではありません。
- 一部画面の未接続項目・無効ボタン、詳細な学校・仕事・健康・社会システムは残っています。
