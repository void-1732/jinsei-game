# 第10段階 実装報告書 — 求人・職業適性・経営拡張

## 実装範囲
- 第9段階の61画面・9カテゴリ・既存IDと日本語表示を継承。
- 仕事・経営画面に架空企業6社の求人カード、応募、評価結果、採用履歴を追加。
- 5科目の平均・関連科目・技能・職歴から算出する決定的な採用評価（乱数による面接評価は未実装）。
- 企業別の就職および在職中の転職。応募に不合格でも既存の勤務先は維持。
- 勤続12か月以上・評価45点以上の昇進審査、役職1～5級・昇進時の昇給。
- 起業後の従業員採用（最大20名）、経営方針（安定・成長・節約）と月次売上・経費の連動。
- 保存データの追加項目は任意として扱い、既存第9段階の形式（スキーマ7）と互換性を維持。
- 新規ゲーム処理は `js/core/careerSystems.js`、画面表示は `js/ui/economyPanels.js`。

## 確認済み
- `npm test`：49件すべて成功（旧44件＋新5件）。
- 年齢制限、成績不足による採用見送り、採用・転職、昇進、従業員採用・経営方針変更、月次収支、旧セーブ形式の読込を自動テスト。
- 既存の画面カタログ試験によって61画面IDの登録・整合性を確認。

## 未確認・残課題
- 実際のブラウザでの操作（画面崩れ・クリック・localStorageの永続性）、HTTPサーバー経由での起動は今回未検証。
- 面接の選択分岐、企業ごとの独立した業績・従業員個別管理、現実の労働法規・税制は未実装。
- 新求人の選考はゲーム内の簡易点数式。企業・数値は架空。
- 旧 `findJob` アクションは内部互換用に保持するが、新しい画面の就職導線は `applyJob` を使用。

## 起動
ZIP展開後、同梱の `start-windows.bat` または `start-local.sh` を実行し、表示されたローカルURLをブラウザで開く。ブラウザに保存するデータの消失に備え、必要に応じて手動セーブ枠も利用する。
