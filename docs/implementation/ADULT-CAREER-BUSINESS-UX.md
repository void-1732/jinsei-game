# 成人期の職業進行と起業画面改善（レビュー）

## 問題と原因
- 事業設備の点検・修理・保守・売却などが画面に存在していたが、ゲームストアの操作受付に登録されず、押しても「未対応」になる。
- 統合画面側が1回の自由行動後にすべてのボタンを無効化し、設備管理や詳細画面の選択を阻害した。
- 設備3台でも同じ5ボタンが台数分並び、起業の経営指標・融資表・取引履歴が延々と積み重なる。
- ページ下部に「操作する項目」ボタンがあり、画面上部のカテゴリ内タブと役割が重複した。

## 修正
- 設備の操作名すべてをゲームストアに接続し、押すと実際の状態・資金・履歴に反映する。
- 「人生の自由行動」月1回とは別に、事業経営中の設備・融資・従業員管理を月3回まで可能とする。重要イベント未選択中は両方とも停止。操作できない場合の理由は提示する。
- 事業設備一覧は対象1台をボタンで選び、状態・保守・点検・修理・売却を一か所にまとめる。設備購入・買い替えは同パネルの開閉欄に配置。
- 経営トップは「営業状態・事業資金・稼働設備・従業員・融資・見込売上」をまとめ、長い融資・帳簿・従業員情報を開閉可能にする。
- 既存の画面IDは削除しない。画面切替ボタンはページ上部の共通ナビに集約し、詳細領域内には重ねて置かない。
- 求人応募と就職後キャリアの画面を分け、勤続と役職で職業の段階を示す。働き方は「安定重視」「専門性重視」「管理職を目指す」の3つからボタンで選ぶ。月次の職場成績に小さく反映する。

## セーブ
- スキーマv7継続。新設した `businessTurn` と `career.plan` は任意フィールドとして検証し、旧セーブはロード時に補完する。
- 既存の事業資金・設備・融資契約・給与履歴を初期化しない。

## 検証
- `npm test`、公開設定検査、正式版回帰、PC 1440px・スマートフォン390pxのブラウザ検証。
- ブラウザでは実際に設備の点検ボタンを押し、人生自由行動を消費した後でも別枠の事業管理として成功することを検証。
- 全項目を通過するまで `main` へマージしない。
