# 第21段階 実装・検証報告

## 基準
第20段階ZIP（バージョン2.1.0）を展開し、変更対象ファイルのみ更新。既存55画面ID・新規学業6画面IDの計61画面IDを継承。

## 実装済み
- 融資契約別の月額予定元本返済（0～500,000円／月）を設定・解除。従来の事業全体返済設定との併用可能。
- 返済予定表を現在の契約情報から12か月先まで参照表示。予定額・参考利息・残高・期限到来を表示。これは予測であり資金不足や将来の業績変化は考慮しない。
- 月次の予定元本額と実際の返済額を契約ごとに記録し、差額を画面表示。履歴は最大120件。
- 設備種別（標準設備100か月、事務機器60か月、製造機械120か月、車両72か月、店舗設備96か月）を選択して購入。初期設定は互換性のため標準設備。
- 種別・経過月数・残耐用月数を設備台帳に記録。個別売却時の簡易経年劣化係数を追加。
- 新項目の保存形式検証。第20段階の旧保存データに項目がない場合は既定値で動作。
- 操作ラベルと説明は日本語。既存61画面IDと9カテゴリは不変。
