# 成人期の選択肢・画面整理（改善版レビュー）

## 目的
正式版 v6.0.0 の現行セーブを維持したまま、重複した情報表示を減らし、18歳以降の意思決定を増やす。これは正式版を置き換える前のレビュー用変更である。

## 画面変更
- 61件の画面IDと9カテゴリは維持。保存互換や画面遷移のIDを改名しない。
- まとめページの「現在の状況」は重複するフィールド名を除外し8項目まで表示。
- 「詳細・個別操作を見る」では選択した旧画面を1件だけ描画する。複数の大きな操作パネルを同時展開しない。
- モバイルでは要約を1列にし、詳細画面セレクタは幅100%にする。

## 成人後に選べる内容
- **アルバイト・副業**: 店舗、カフェ、家庭教師、配送補助、在宅入力、デザイン制作。月間勤務時間と時給が異なる。既存の `sideJob` を利用。
- **投資**: 定期預金型、債券型、株式インデックス型、個別株型、REIT型。保有額を商品別に表示。月次評価額は再現可能な簡易モデル。旧データの未分類投資は分離して保持。
- **車**: 軽自動車、コンパクト、ファミリー、ハイブリッド。現金購入、毎月の維持費と減価、売却額、純資産への反映。
- **任意保険**: 従来3プランのほか、医療重点、がん・重病重点、生活防衛。既存の1件加入と給付ロジックを維持。
- **進学候補**: 工業・商業・通信制高校、国公立・私立大学、短大・専門学校を志望先として追加。ただし学制の年限は従来の大学ステージを使用する暫定仕様。進路ごとの2年制・4年制と資格接続の実装は別途必要。
- **住宅**: 既存の10地域×実家/賃貸/持ち家、住宅ローンと購入・売却を保持。持ち家は小さな戸建て・標準住宅・大型物件の3段階を選べ、取得価格と維持費が変わる。

## 既存ゲームとの互換
- スキーマバージョンは7のまま。任意の `investmentHoldings`、`vehicle` を補完。
- 車の資産価値を遺産・純資産に加算し、旧データには車の項目を増やさない。
- 既存の `buyInvestment` で商品IDを省略した操作の処理は変更しない。
- 投資、住居、保険は教育用の架空モデル。実在の市場価格・商品・税・保障制度を再現しない。

## リリース条件
`npm test`、`npm run check:pages`、PC/スマホのブラウザ操作・保存復元テストを実行する。通過結果を確認するまで `main` には統合せず、GitHub Pages 正式版は更新しない。
