## 調整方針

- 自動昇給：勤続初期・中期・後期の月給上昇幅を段階的に減らし、自動昇給だけで月給42万円を超えない。手動の昇進・交渉の成果は維持。
- 高齢期給与：65歳以降は月次受取給与の係数を抑え、年齢によらず毎月最高給与が続く問題を緩和。仕事自体は自動終了させない。
- 長期失業：就業機会のない期間の生活費を徐々に抑制。ただし最低生活費を残し、負債が消える仕組みではない。既存の生活費予算・時間配分による節約も有効。
- 進学・就職：既存の志望校判定で受験準備の蓄積を適切に考慮。資格・採用・業種条件は保持。
- 健康と寿命：低体力・低精神状態が高齢期リスクに反映。既存の年齢進行と110歳上限は維持。
- イベント頻度：慢性的な健康不良で毎月同じ警告が並ぶ状態を避け、初回と定期的な再警告を維持。3択イベントは従来どおり1ターン最大1件。
- 時間配分：仕事を継続した場合の疲労・ストレス上昇に漸進的な自然適応を導入。休養とのトレードオフを残しつつ、仕事を選んだだけで必ず両方100になる状態を避ける。
- 能力成長：既存の95点到達制限・高得点時の成長鈍化を保ち、継続行動の成果が失われないことを再検証。
- 旧保存：スキーマ番号7と既存のフィールドを維持。読み込み時に状態を強制変更しない。
