# U4 → U5 → U7 : 資産・家計予測、行動ナビ、成人期の長期分岐

## U4（A＋C）家計・資産の一括管理
- 既存の「生活・資産」→「家計・資産」→「家計簿・収支（LIFE-03）」に、現金・投資・車・不動産・負債・純資産の6指標をまとめる。事業資金を個人の現金と混同せず、純資産には既存の事業口座・設備・負債を一度だけ計上。
- 月額の本業・副業・賃料・年金等の受取額、給与税相当、生活費、車維持費、保険、年金、物件維持費、ローン返済予定、継続習慣の費用を明示。
- 1・3・12か月先の現金残高を、**今の収入と固定費が継続する**仮定で概算。相場・金利変動、失業、家族イベント、学費、税変動、物件空室等を確定予測しない。赤字予測のときは警告。
- 既存の生活費設定と過去12か月の収支グラフは折りたたみから利用できる。住宅・車売買、投資、返済額設定などの詳細操作も従来画面に残す。

## U5（A＋B）状況に合ったおすすめと注意
- 人生ダッシュボード内で、年齢・勤続・家族・現金・家計見込・住宅ローン延滞・体力・こころ・病気の状態を参照。
- 危険の高いものを優先して2件表示。追加の注意事項はコンパクトに折りたたみ、単なる確認では自由行動枠を消費しない。
- 就職・健康・家計など、既存の関連画面へボタンで誘導。65歳以上の無職状態を通常の失業警告と誤判定しない。利用不可の行動を強制しない。助言は常に読み取り専用。

## U7（A＋B）社会人以降の選択肢・長期分岐
- 「お金と暮らしの選択」24〜26歳開始・35歳・50歳の継続、「仕事と大切な人」28〜30歳開始・42歳・58歳の継続を追加。
- 各分岐に3つの進路と、過去に選んだ道を踏まえた続編を用意。既存の重要イベントを阻害せず、当時の決断と学習・仕事・心身・人間関係の変化を記録。
- 既存の5年後・15年後の帰結システムにも結びつける（長期影響を新規の保存構造ではなく既存の影響度記録へ統合）。
- 保存形式v7・画面ID61件・従来の進路分岐・保存済み人生を維持。新しい別画面・重複した操作ボタン・経済的な無料報酬は追加しない。

## 品質ゲート
- 新規の固定費計算、二重資産計上の防止、年齢・職業別の助言、数十年の分岐継続、旧セーブ互換を自動テスト。
