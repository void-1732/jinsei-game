# STEP 55 完成度総点検 — 回帰検証とリリース確認

## 方針

新しいゲーム機能は追加しない。既存の人生イベント、長期分岐、進学、就職、家計、健康、社会情勢、災害、生活習慣、セーブ、エンディングの長期整合性を確認する。

## 自動検証

- `npm test`: 既存の317件に、生涯プレイ3件と旧版セーブの復旧1件を追加した321件。
- 生涯プレイ: 生年月日・乱数シードと人生方針の異なる3名を出生から死亡まで進める。幼少期の3か月ターンと成人後の毎月ターンを含む。
- シナリオ: 学習重視・健康重視・人間関係重視。学習・健康シナリオでは就職を試み、交流シナリオでは無職を続けた場合の家計悪化も比較対象にする。
- 全ターン: 選択イベントの解決、保存形式の検証、日付単調増加、現金・負債の非負制約、健康・ストレスの範囲、履歴長上限。
- 18歳・45歳・65歳付近: 手動保存・ポータブルJSONの書き出し・読み込み、乱数と未決定イベントの一致確認。
- 終了時: 死亡後の進行禁止、終了情報・相続・人生振り返り、人生記録スロットへの保存。
- 従来セーブとの互換性: 新しい生活プラン・目標・長期的選択等を含まない形式を読み込み、進行できること。

## ブラウザ・レスポンシブ検査

ChromeヘッドレスのDevTools Protocolを利用し、1440px（PC）と390px（スマートフォン）で以下を実操作する。

- 初期状態・9カテゴリ表示と横方向のはみ出し防止。
- 新しい人生の開始、次ターンの3択イベント、選択後のポップアップ終了。
- カテゴリの開閉、設定ダイアログ、保存ファイル入出力の操作要素。
- JavaScriptの未捕捉例外が発生しないこと。

実際のレンダリングを伴うブラウザ検査は `node scripts/qa-browser.mjs` で実行する。ChromiumまたはChromeが必要。

## バランス検証上の注意

就職しない人生では、成人以降の生活費が負債として累積する。これは生活費を支払う収入がないシナリオで生じる結果であり、直ちに二重請求を意味しない。就職したシナリオと分けて検査する。現実の経済・健康・寿命を正確に再現したモデルではない。

## 公開

GitHub Actions `pages.yml` で `npm test` → Chrome両画面の操作検査 → Pages参照ファイル検査 → 公開用ファイル生成 → GitHub Pagesへ公開を行う。いずれかの検査が失敗した場合はデプロイしない。
