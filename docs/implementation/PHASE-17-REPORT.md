# 第17段階 実装報告書

## 実装概要

第16段階（1.7.0）を基準に、第17段階（1.8.0）で個人事業の融資、返済、利息、設備売却、独立した事業取引履歴と、失業給付の再受給条件を追加しました。既存55画面＋学業6画面＝61画面、9カテゴリ、画面ID、および保存スキーマ7を維持しました。

## 実装済み

1. 事業融資：1回最大50万円、融資残高最大200万円。融資元本は事業口座に入金され、純資産には負債として控除。返済は事業資金から行い、個人の現金を直接変動させない。
2. 融資利息：月利0.5%の単純化した固定金利。毎月事業口座から支払い、不足分は事業未払金に計上。実際の金融機関の金利ではない。
3. 事業設備：運転資金による設備購入、帳簿価額70%での一括売却。廃業には融資返済と設備売却が必要。売却損を純資産へ反映。
4. 独立事業台帳：売上、経費、融資借入・返済・利息、設備、事業主からの出資と引出しを別台帳で記録。直近240取引まで保持。個人の取引履歴は従来どおり維持。
5. 再受給制限：6か月の給付を満了した場合は、新たに12か月の勤務実績を積むまで次の受給を停止。従来の6か月上限や自主退職時の給付なしを維持。
6. 事業・家計画面に融資・返済・設備購入・売却の日本語操作ボタン、残高、取引履歴を追加。
7. 旧保存スキーマ7の任意項目を読み込み時に補完し、新しい融資・設備・台帳項目の不正値を拒否。

## 互換性・制約

- 既存の無条件就職操作 `findJob` は旧コード・自動テストとの互換性のため内部に残しています。通常の求人画面では企業別採用選考 `applyJob` を使用します。無条件就職の内部経路の完全廃止は未実施です。
- 過去の取引明細は遡及生成しません。第17段階への更新後からの事業取引が台帳に記録されます。
- 設備の減価償却、融資審査、利息の複利計算、返済期日、複式簿記、消費税は未実装です。
- 事業の既存未払金 `operatingDebt` と今回の融資元本 `loanBalance` は別項目です。融資残高をゼロにしても未払金が残る場合、廃業時に個人の負債へ引き継ぎます。
- 失業給付と融資は架空のゲーム用ルールです。日本の現実の制度ではありません。
- 「企業再建時の経営方針」は第16段階の再建支援を維持し、追加の経営選択分岐は未実装です。
- 企業別の月次グラフは未実装。現状は最近の数値履歴で確認します。
